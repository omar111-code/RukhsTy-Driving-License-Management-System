# RukhsTy – Driving License Management System

**Graduation Project | Software Engineering**

## Project Overview
RukhsTy is an academic graduation project that aims to digitize and streamline driving license services in Jordan. The system is designed to manage the driving license application process, application tracking, officer evaluations, and digital license verification.

## Key Features
- User registration and authentication
- Driving license application and status tracking
- Role-based dashboards for administrators and officers
- Medical, theoretical, and practical evaluation workflows
- Digital driving license with QR code verification
- Simulated payment and delivery workflows

## Technologies
- React and TypeScript
- Node.js and Express.js
- PostgreSQL
- JWT authentication
